# 🎓 AI Mastermind Certificate Generator

A simple web-based Certificate Generator that allows users to enter their details and instantly generate a professional certificate as a downloadable PDF.

## 🚀 Features
- Live certificate preview
- User details input (Name, Email, Mobile)
- Optional signature upload
- Download certificate as PDF
- Clean, responsive UI

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- html2canvas
- jsPDF

## 🌐 Live Demo
👉(https://pralhadt.github.io/certificateGenerator/)
## 📸 Preview
Users can fill in their details on the left panel and see a real-time certificate preview on the right, then download it as a PDF.

## 📂 How to Use
1. Open the live demo link
2. Enter your details
3. Click **Preview Certificate**
4. Click **Generate PDF**

## 📌 Note
Make sure to enable GitHub Pages in your repository settings to host the live demo.
